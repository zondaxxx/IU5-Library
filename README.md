# Библиотека ИУ-5

Каталог открытых учебных материалов ИУ-5: [iu5.api-gate.org](https://iu5.api-gate.org).

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Сайт написан на React и Vite. Каталог находится в `public/documents/index.json`; страницы и поиск работают без серверного API. Избранное хранится в localStorage браузера.

## Синхронизация материалов

```bash
python3 scripts/sync_yandex.py
```

Скрипт обходит публичную папку Яндекс Диска, обновляет каталог и загружает PDF, офисные документы, текстовые файлы и сканы в `public/documents/files/`. Прочие файлы тоже присутствуют в каталоге, но открываются по исходным ссылкам на Яндекс Диск. Повторный запуск пропускает файлы, размер которых не изменился. Для повторной попытки без обхода папок используйте `--use-index`; для обновления только списка — `--index-only`. На сервере без рабочего IPv6 добавьте `--ipv4`. Ошибки загрузки записываются в `public/documents/download-errors.txt`, а соответствующие позиции каталога переключаются на исходные ссылки.

Бинарные файлы исключены из Git. Для полноценной публикации их нужно перенести на сервер отдельно.

## Сборка и размещение

```bash
pnpm typecheck
pnpm build:client
```

Сборка в `dist/spa/` включает приложение и `documents/index.json`, но не копирует массив документов. В Caddy корень сайта — `/srv/iu5/current`, а `current/documents/files` указывает на `/srv/iu5/files`. Caddy отдаёт файлы напрямую; для клиентских маршрутов используется `index.html`. Обновлять код и каталог можно независимо от документов.
